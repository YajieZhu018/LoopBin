# LoopBin Python environment, managed with uv instead of conda.
#
# Covers the model/training stack (pretrain/train/cluster/merge/calculateg/nmi
# stages): tensorflow, numpy, scipy, scikit-learn, kneed, matplotlib, pandas,
# h5py. All versions below were installed and verified working together
# (TensorFlow imports, forward pass, and sklearn GaussianMixture all tested)
# on Python 3.9 via uv on this cluster.
#
# NOT yet covered: the raw preprocessing/process stages additionally need
# cooler, cooltools, bioframe, pysam, pytables, biopython, and the
# ucsc-bigwigaverageoverbed binary (see loopbin.yml/loopbin_core.yml, the
# original conda specs). Some of these (pysam, pytables) build C extensions
# against system libraries (htslib, HDF5) and may need extra setup via pip/uv;
# ucsc-bigwigaverageoverbed is a bioconda binary with no PyPI equivalent and
# needs a separate install path. Not yet ported/verified here.
#
# To recreate:
#   module load uv
#   uv venv --python 3.9 loopbin
#   source loopbin/bin/activate
#   uv pip install -r requirements.txt
#
# Note: tensorflow==2.5.0 pulls in protobuf==6.x by default via uv's resolver,
# which breaks tensorflow's own generated _pb2.py files at import time
# ("Descriptors cannot be created directly..."). protobuf is pinned to 3.20.3
# below to avoid this — do not let it float.
